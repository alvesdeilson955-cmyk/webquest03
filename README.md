# WebQuest 03 - Agenda Eletrônica

Este repositório contém o projeto da atividade WebQuest 03, desenvolvido em Java.

O sistema permite:

- Adicionar contatos
- Buscar contatos
- Remover contatos
- Listar contatos
- Salvar e carregar dados em arquivo CSV

O projeto foi feito utilizando:
- Java
- VS Code
- Git e GitHub
